Animations

Animations are used to move/change elements automatically without hover or click

@Keyframes

A Keyframe is used to define the different stages of an animations


A Keyframe contains two stages

1. Two Stages Syntax

In this we only have "from" and "to"

                            @Keyframes animationName{ 

                                from{ 

                                    /Start/ 

                                } 

                                to{ 

                                    /End/ 

                                } 

                            }

2. Three or more Stages Syntax

In this we have % syntax

                            @Keyframes animationName{ 

                                0%{ 

                                    /Start/ 

                                } 

                                50%{ 

                                    /Middle/ 

                                } 

                                100%{ 

                                    /End/ 

                                } 

                            }
